# Master Thesis: Design and Implementation of Real-Time Packet Scheduling Mechanisms using Programmable Queues
This repository contains all artifacts of my master thesis.


## Omnet++ Simulation
The project contains the implementation of the PIFO and PIFOCD designs as well as the simulation used for the evaluation in the report.
The simulation is based on `inet-4.6`.

## Evaluation
The python scripts where used to generate the relevant parts of the `.ini` files for the simulations and the plotting of the data from the `.vec` files, generated by omnet.

## Lean4 Proof
The lean file contains the full proof of the formal analysis outlined in the report.
The file can be run using a normal lean-project and the standard lean4 compiler.
